# Ytdlp Telegram Bot

Python-based modular Telegram media bot.

## Development approach

The project is being built incrementally. Each step is tested before the next subsystem is added.

## Step 1

- Python project foundation
- Environment-based configuration
- Portable runtime directories
- Colab launcher
- Kaggle launcher

Telegram, search providers, automatic URL detection, yt-dlp, aria2c, FFmpeg, Telegram uploads, GoFile uploads, and job processing will be added in later steps.
